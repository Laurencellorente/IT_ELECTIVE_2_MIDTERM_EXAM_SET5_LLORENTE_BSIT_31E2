# Equipment Borrowing & Monitoring System
Hello My Name is Laurence Llorente From Lyceum of alabang and This is my simple equipment borrowing and monitoring system built with ASP.NET Core MVC.
It gives you an easy way to keep track of who borrowed what, when it’s due back, and whether it’s been returned yet. THIS IS JUST MY EXAM SYSTEM OKAY.

- BSIT_31E2

---

## ⚡ What It Does

**Clickable Stats**: Click any card at the top (Total, Borrowed, Returned) to filter the list instantly.
**Instant Search**: Type in the search bar to filter borrower, item, or TXN details live as you type.
**Quick Loan Setup**: Easily log equipment borrowed by students or faculty.
**Easy Returns**: Mark borrowed items as returned with a single click.
**Dark Mode UI**: Built with a clean dark glass theme and Bootstrap icons.

---

## 🛠️ Built With

* **Backend:** C# / ASP.NET Core MVC (.NET 8)
* **Frontend:** Razor Views, Bootstrap 5, Bootstrap Icons, Vanilla JavaScript
* **Database:** Entity Framework Core (SQL Server / LocalDB)
